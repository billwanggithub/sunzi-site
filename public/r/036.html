第 36 則 · 行軍篇 第九

令之以文,齊之以武

行軍篇(第 3 則)十三篇 · 9 / 1336 / 51
兵非益多也,惟無武進,足以併力、料敵、取人而已。夫惟無慮而易敵者,必擒於人。卒未親附而罰之,則不服,不服則難用也;卒已親附而罰不行,則不可用也。故令之以文,齊之以武,是謂必取。令素行以教其民,則民服;令不素行以教其民,則民不服。令素行者,與眾相得也。

白話翻譯 TRANSLATION

兵力不是越多越好,只要不輕敵冒進,能夠集中兵力、判斷敵情、得到部下擁護就足夠了。那些沒有深謀遠慮又輕視敵人的,一定會被敵人俘虜。士兵還沒有親近依附就施加懲罰,他們會不服,不服就難以使用;士兵已經親近依附,卻不執行軍紀,也無法使用。所以要用道理和恩惠教育士兵,用軍紀刑罰統一步調,這樣就一定能取勝。平時就嚴格執行命令來教育士兵,士兵就會服從;平時不嚴格執行命令,士兵就不會服從。平時命令能貫徹執行,是因為將領與士兵相處融洽、互相信任。

重點解析 KEY POINTS

  • 「兵非益多」:人多不一定好,重點是集中、判斷和人心。
  • 文武並用:先建立信任(文),再嚴格執行紀律(武),順序不能顛倒。
  • 「令素行」:規矩要平時就執行,不是出事了才拿出來。

現代應用 HARDWARE & SOFTWARE

  • 團隊不是越大越好。加人進一個延遲的專案,往往會讓它更延遲(布魯克斯法則)。
  • 新進成員還沒建立信任前,就嚴厲批評他的程式碼,只會讓他不服。先帶著他熟悉環境,建立關係後再要求標準。
  • Code review 規範、測試覆蓋率要求、上線檢查表,要平時就落實。只有出事時才嚴格執行,大家不會真的遵守。

股市投資 INVESTING

  • 資金不是越多越好賺。資金規模太大反而會限制你能投資的標的,紀律比規模更重要。
  • 「無慮而易敵者,必擒於人」:輕視市場、以為自己能輕鬆賺錢的人,通常會被市場教訓。
  • 投資紀律要「素行」:停損規則、部位上限要每一次都執行,不能因為這次特別有信心就例外。
